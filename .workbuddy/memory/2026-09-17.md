## v4：修复卡片纵向压叠 + 新增 Skill 装配体系
- 用户提出两个问题：① 叶子层卡片垂直方向互相压叠严重；② 把 PRD 的 skill 体系（截图为准）全部加进导图，以最终形态呈现。
- **① 布局根因**：旧布局用固定行距 `Y_STEP=38`，而长卡片实测最高 **131px**（headless 实测），必然压叠。且 `#world` 宽度由 `maxX`（用常量 NODE_W 估算）决定，导致绝对定位卡片的 shrink-to-fit 宽度被裁、长文本强制换行增高。
  修法（v4）：
  - 卡片改为**定宽**（渲染时内联 `width:NODE_W[type]px`），使高度可预测；
  - `render()` 改为三段式：**先建成 DOM → 实测 `offsetHeight` 写入 `MEASURED[]` → 再 `layout()` 定位**；`heightOf(n)` 优先实测、`estHeight()` 按字符宽度（CJK 全宽/西文半宽）估算兜底；
  - `layout()` 按叶子真实高度累加（`V_GAP=16`），`fitView`/画布尺寸统一用 `heightOf`。
  - 验证：headless chromium 自检 `overlap=0, minGap=16.0`；node 桩复检 227 叶 0 重叠。
- **首屏可读性**：默认只显示主干 **13 个节点**（root + 7 阶段 + 6 贯穿视角），`focusTop()` 1:1 顶部对齐（不再 fitView 到 0.27 糊成一片）；按钮改为「逐层展开」（只展开当前可见且折叠的节点，需 `isVisibleNode()` 判祖先链，否则会被 kept 全量误导而一次全展开）/「全部收起」/「适配视图」/「导出大纲」。筛选 chip 也只展开"有匹配后代"的节点。
