# 2026-09-20

## 新增登录与用户权限系统（login + RBAC）

为 firstFlight 后端（FastAPI + SQLAlchemy/SQLite `gateway.db`）新增了登录与权限体系：

- **零依赖实现**：因 PyJWT/bcrypt 安装受阻，认证改用 Python 标准库实现
  （`app/security.py`：PBKDF2-HMAC-SHA256 密码哈希 + HMAC-SHA256 签名 token）。
- **User 模型**：`app/database/models.py` 新增 `users` 表（username/password_hash/role/is_active）。
- **identity 模式新增 `auth`**：`app/identity.py` 的 `ActorResolver` 在 auth 模式下从
  `Authorization: Bearer` 解出 actor=登录用户名；`config.py` 增加 `auth_jwt_secret`/`auth_token_ttl_seconds`。
- **接口**：`app/api/auth.py`（`/api/auth/login`、`/me`、`/change-password`）；
  `app/api/admin_users.py`（`/api/admin/users` 列表/创建/启用禁用/重置密码/删除，仅 admin）。
- **种子用户**：`app/auth/seed.py` 在 lifespan 启动时空表自动写入 `owner-1`(password123, role=owner)
  与 `admin`(admin123, role=admin)。历史数据仍归属 owner-1（原 `.env` 强制 actor=owner-1）。
- **前端**：`frontend/aios-main` 新增 `src/auth/session.ts`、`LoginPage.tsx`、`AdminUsersPage.tsx`；
  `src/api/client.ts` 自动附带 Bearer；`App.tsx` 无 token 时展示登录页；`CURRENT_ACTOR_ID` 改为当前登录用户。
- **配置**：`.env` 已切到 `FIRSTFLIGHT_IDENTITY_MODE=auth` 并写入 `FIRSTFLIGHT_AUTH_SECRET`。
