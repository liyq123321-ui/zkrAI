## 新增：自运营 MCP Gateway（Python 版，挂载进现有后端）

- 依据 `~/Downloads/mcp-gateway-build-spec.md`，但**没按 spec 用 TS**：改成 Python + FastAPI，
  包 `backend/app/mcp_gateway/`，挂载到既有后端 8088 → 端点 `POST /mcp`（Streamable HTTP，
  手写 JSON-RPC 2.0 分发，JSON 或 SSE 响应）。理由：后端已单进程 FastAPI，避免新增 Node
  进程/端口与运维面。`MCP_GATEWAY_ENABLED=0` 可关闭挂载；`python -m app.mcp_gateway.standalone`
  可单独起（默认 8099）。
- 模块：config（YAML + 环境变量覆盖）/ errors（-32000~-32005）/ auth（静态 token + 签名 token，
  兼容 firstFlight 两段式与标准 HS256 JWT）/ exposure（deny-all + fnmatch 通配）/ ratelimit
  （进程内滑动窗口）/ audit（JSONL + 内存环，字段脱敏）/ protocol（initialize、tools、
  resources、prompts、ping）/ router（/mcp + /mcp-gateway/* 管理端点）/ adapters
  （builtin、http-json 含异步轮询+图片提取、rag-knowledge、external-mcp 级联）。
- 配置：`app/mcp_gateway/config/gateway.yaml`（agents 白名单）+ `skills.yaml`（8 个技能）。
  文档 `docs/mcp-gateway.md`（含上线前注意事项清单），CLI `backend/scripts/mcp_gateway_call.py`。
- 测试：`tests/unit/test_mcp_gateway.py` + `test_mcp_gateway_policy.py`，27 项全绿。
  全量 `tests/unit` 477 passed / 2 failed，两个失败均为既有基线（agent_gateway 的 drawio 提示词
  断言、ai_sentence_stream 的 CRLF 行距启发式），与本次改动无关。
