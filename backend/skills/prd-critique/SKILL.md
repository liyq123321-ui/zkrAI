# PRD Critique

Evaluate the supplied PRD evidence across problem clarity, users, goals and metrics,
scope and non-goals, requirement quality and priority, edge/error cases, acceptance
testability, assumptions and tradeoffs.

Identify concrete defects and propose the smallest evidence-backed correction. Flag
metrics theater, feature lists without a problem, solution-smuggled problem
statements, unsupported claims, duplicated requirements and scope creep. Do not
invent a product decision to improve a score. When the host requests corrected
content, apply the correction while preserving valid wording and identifiers.
