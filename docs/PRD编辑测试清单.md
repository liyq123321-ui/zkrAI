## 0. 通用约定与已知边界

| 项 | 说明 |
| --- | --- |
| 后端无 `--reload` | 改 `backend/app/**` 后必须**重启后端**才生效；前端 HMR 刷新即可。 |
| 身份模式 | `backend/.env` 默认 `FIRSTFLIGHT_IDENTITY_MODE=auth`（Bearer）；`<img>` 无法携带 token，图片必须走 `DocumentAssetImage` 组件 + token 拉取（`FIRSTFLIGHT_IDENTITY_MODE=legacy` 才会 401 于部分接口）。 |
| 一次最多 8 章 | `MAX_SCOPE_CHAPTERS = 8`；结构化修改超过 8 章报错「请选择明确的目标章节，最多一次修改八个章节」，或拆成多份候选组。 |
| 候选不自动应用 | 结构化/批量/工作台修改只生成**候选（ready）**，必须经预览明确应用才写正文。 |
| 显式保存 | 人工输入约 900ms 按 Block 保存；未保存草稿不进入 Agent 上下文。 |
| 单进程约束 | 后端单进程单 worker；同块只能一个活动作业；≤3 个 AI 调用并发。多 worker 会破坏命令 ownership。 |
