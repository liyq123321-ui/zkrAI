# 子 WorkItem 对话入口与员工选择需求

状态：2026-09-03 子 Agent 与员工选择为前端实现；后续按用户明确要求补充数据库共享看板和 Root 多选筛选。

## 本轮范围

子 Agent 对话及员工指派仅修改前端与文档，不新增员工数据库、权限逻辑或真实子 Agent 执行流程。共享看板新增只读 `GET /sessions` 数据库目录接口，用于展示全部已保存项目。

## 子 Agent 对话区

- 每个非 ROOT WorkItem 的详情中，在规格正文前展示独立的「子 Agent 对话」卡片，无 Agent Spec 的子任务也可显示。
- 卡片包含「人工指令优先」说明、待接入状态、空会话说明、可编辑输入框及发送和中断入口。
- 「修改需求」快捷按钮聚焦输入框，只在空草稿中填入提示，不覆盖用户已写内容。
- 发送和中断按钮禁用；明确告知子 Agent 尚未接入，不模拟回复、不改变真实需求或任务状态。
- 草稿按 Session 和 WorkItem 隔离保存在当前页面内存，关闭详情后重新打开可继续填写；刷新页面后清空。不写入 localStorage 或服务端。

## 员工选择

- 「责任 Agent」卡片增加带标签的员工下拉框，可选择员工及「未指派」。
- 前端独立维护 `EmployeeOption` 名单类型及演示目录，并合并现有 WorkItem/Agent Spec 的负责人，保留不在演示名单中的历史值。
- 示例员工明确标注「示例」，不把示例身份当成真实员工。当前角色信息继续展示。
- 选择后立即在本页详情、看板和任务流转图中预览；关闭后再打开保留本页选择，刷新后恢复后端原值。
- 人工选择优先于原建议负责人；清空指派不得回退显示原建议人。
- 前端注明「仅本页预览，刷新后恢复；不会保存到服务端」。不发送指派请求、不修改已有 API DTO 或权限。
- 后续接数据库时，由上层加载员工目录并传入组件，替换名单来源；真实保存接口属于后续工作。

## 补充：项目对话中的新任务入口

- 已打开项目时，左侧 Agent 对话面板顶部提供「创建新任务」按钮，与刷新状态同处操作栏。
- 点击后复用现有新项目需求表单；提交「创建并分析」后才调用现有创建流程。入口本身不发送请求、不删除原项目数据。
- 正在处理请求时禁用入口，避免中途切换；窄屏允许操作栏换行。

## 数据库共享看板与 Root 多选

- 看板展示数据库内全部项目的 WorkItem，不以浏览器访问过或恢复过的 Session 作为数据范围。页面加载和「刷新看板」读取完整项目目录。
- 「创建新任务」只切换左侧需求表单；新建成功后任务并入共享集合，旧项目卡片继续保留。左侧「当前对话」可以切换项目，右侧不随之切换数据范围。
- 在搜索框旁增加「主任务」下拉多选，名称来自项目需求（Root）的主 WorkItem，按 Root ID 区分。默认全部显示，支持多选、全部任务和清空选择。
- 选择的项目显示 Root、里程碑及其全部子 WorkItem；再叠加已有关键词、类型、执行者过滤。新建与切换对话不重置选项；刷新页面恢复默认全部。
- 从任一项目打开的详情及 PRD、人工确认命令必须绑定该项目的 Session 和版本，不能使用当前对话的项目状态。子任务草稿继续按所属 Session 与 WorkItem 隔离。
- 某项目加载失败时保留其他成功项目并提供重试提示。后端目录仅查询数据库，不修改任务或运行 Agent。

## 布局与可访问性

延续现有浅色详情样式，桌面端对话卡片位于左侧正文顶部、员工选择位于右侧责任卡片。窄屏使用单列顺序，控件不超出对话框宽度。输入框、下拉框、按钮具有清楚的标签与键盘焦点。

「依赖关系」中的 WorkItem 以名称和编号展示，可点击切换到对应详情。导航从完整项目集合查找目标，不受看板筛选影响；切换后回到详情顶部，原任务草稿和筛选保留。无法加载的依赖保留编号并显示不可用状态，避免打开空白详情。

## 验收

1. 原有需求、实施方案、任务状态和 PRD 流程继续可用。
2. 不同任务的草稿与员工选择不串线；关闭重新打开保留，页面重新加载恢复初始值。
3. 员工选择在详情、看板、筛选及任务流转图中一致显示。
4. 对话、快捷填入、指派预览均不会新增网络请求；发送与中断始终禁用。
5. 前端测试、类型检查、生产构建通过；浏览器验证宽屏与窄屏。
