## 三、一句话选型总览

- **框架**：后端 FastAPI + SQLAlchemy(SQLite) + Pydantic + Codex/OpenAI 网关 + Gitea；前端 Vite6 + React19 + TS + Tailwind v4 + react-markdown。全部轻量、零重型中间件。
- **结构**：靠 **FSM + 两阶段命令引擎 + 不可变版本 + DAG 校验 + Gitea 绑定 + 混合审核** 实现"可审计、可回放、可人工否决"的流水线；刻意不用 LangGraph/NetworkX 等图引擎（DAG 只校验不调度）。
- **技能**：核心是 **7 个提示词节点 + PM/Reviewer 双角色 + 3 套 SDLC 生命周期模型**；内置 Codex skill 里只有 drawio 真正被加载，其余为储备。
