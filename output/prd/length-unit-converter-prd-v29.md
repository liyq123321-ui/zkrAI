## 2. 业务背景与产品概述

### 2.1 业务背景

用户在阅读海外尺寸、设备规格或其他以英寸为单位的内容时，需要将英寸换算为公制厘米。手工套用公式不便且容易算错，因此需要一个打开即可使用、无需联网的本地换算工具。

### 2.2 产品目标

| 目标 | 目标说明 | 可验证指标 |
| --- | --- | --- |
| 降低换算成本 | 用户无需记忆或手动套用公式 | 输入后一次点击即可得到结果 |
| 保证结果一致 | 统一换算系数、精度和舍入规则 | 指定验收样例结果 100% 匹配 |
| 明确处理错误 | 对空值、非法格式和越界输入给出不同提示 | 规定的异常用例均出现对应文案，且不产生结果 |
| 保持轻量可用 | 应用完全在本机浏览器运行 | 断网、无后端、无数据库时核心功能可用 |

### 2.3 产品定位

在需要快速完成英寸到厘米换算的场景下，为个人用户提供一个轻量、单向、离线运行的 React 单页工具。产品聚焦“输入、校验、换算、重置”四项核心能力，不承担通用单位换算平台的职责。

### 2.4 服务对象

- 需要偶尔进行英寸到厘米换算的个人用户。
- 在 Microsoft Edge 中验收和测试本地页面的开发、测试人员。
- 本期不区分登录用户、访客或管理员，不涉及账号和权限体系。

### 2.5 典型使用场景

| 场景 | 用户问题 | 产品响应 | 用户价值 |
| --- | --- | --- | --- |
| 正常换算 | 已知英寸值，希望快速得到厘米结果 | 校验输入并按固定公式计算，展示两位小数 | 避免手工计算 |
| 边界换算 | 输入 0 或 1000 | 接受边界值并返回准确结果 | 规则明确、结果稳定 |
| 错误纠正 | 输入为空、格式非法或超出范围 | 显示对应错误提示，不显示旧结果或错误结果 | 快速定位问题 |
| 重新计算 | 完成一次换算后希望重新开始 | 点击“重置”清空输入、结果和错误信息 | 降低重复操作成本 |

### 2.6 产品范围与边界

## 3. 产品概念设计

### 3.1 产品逻辑

> 打开页面 → 输入英寸值 → 点击“换算” → 检查空值 → 检查格式 → 检查数值范围 → 计算厘米值 → half-up 舍入并展示两位小数。

任一步校验失败时，流程立即停止，页面只展示相应错误提示，不生成厘米结果。点击“重置”可从任意状态回到初始状态。

## 4. 全局规则

### 4.1 换算与精度规则

1. 换算公式固定为：`厘米值 = 英寸值 × 2.53`。
2. 结果必须采用十进制 half-up 规则舍入到两位小数。
3. 展示值必须始终包含两位小数，例如 `0.00 cm`、`25.30 cm`。
4. 实现时应避免二进制浮点误差改变验收结果；可以使用十进制运算或等价的可靠舍入方案。

### 4.2 输入格式规则

合法格式应满足以下任一形式：

- 整数，例如 `0`、`10`、`1000`。
- 一至两位小数，例如 `0.8`、`0.79`。
- 小数点结尾，例如 `5.`。
- 省略整数部分的小数，例如 `.5`。
- 带前导零的小数，例如 `00.5`。

以下内容属于非法格式：纯空白、单独的 `.`、带 `+` 或 `-` 符号、前后空白、科学计数法、`Infinity`、`NaN`、包含文字、小数点后超过两位。

### 4.3 校验顺序与错误文案

| 顺序 | 条件 | 错误文案 | 结果处理 |
| --- | --- | --- | --- |
| 1 | 输入内容完全为空 | `输入不能为空` | 清除或不显示厘米结果 |
| 2 | 输入不符合合法数字格式 | `有非法输入` | 清除或不显示厘米结果 |
| 3 | 格式合法，但数值小于 0 或大于 1000 | `请输入范围在 0-1000 以内` | 清除或不显示厘米结果 |
| 4 | 格式与范围均合法 | 不显示错误 | 计算并展示厘米结果 |

> 负数包含 `-` 符号，因此按“非法格式”处理，而不是按“越界输入”处理。

### 4.4 全局交互规则

- 用户每次点击“换算”时，系统都必须基于当前输入重新校验，不得复用旧结果。
- 成功结果与错误提示不得同时出现。
- 从成功输入改为错误输入后再次换算，旧结果必须消失。
- 从错误输入改为合法输入后再次换算，旧错误必须消失。
- 点击“重置”后，输入、结果和错误提示必须同时清空。
- 输入框、换算按钮和重置按钮应具有清晰的文本标签和可见焦点状态。
