## 2. 业务背景与产品概述

### 2.1 业务背景

用户查看海外天气、烹饪说明或设备参数时，经常需要将摄氏温度换算成华氏温度。手工套用公式不便且容易出错，因此需要一个无需账号、无需联网、打开即可使用的本地工具。

### 2.2 产品目标

| 目标 | 说明 | 可验证指标 |
| --- | --- | --- |
| 快速换算 | 一次输入和一次点击得到华氏结果 | 正常路径无额外页面跳转 |
| 结果可靠 | 统一公式、边界和显示精度 | 五个规定数值全部符合预期 |
| 错误可理解 | 明确区分空值、格式错误和越界 | 非法输入不显示有效结果 |
| 离线可用 | 完全在本机浏览器执行 | 无后端、数据库或网络时可完成全部核心操作 |

### 2.3 产品定位与用户

产品定位为面向个人用户的轻量、单向温标换算工具。目标用户包括临时查阅海外信息的普通用户，以及负责本地交付验收的开发和测试人员。本期不提供通用科学计算、双向换算、历史记录或账号体系。

### 2.4 范围与边界

| 类型 | 内容 |
| --- | --- |
| 本期包含 | React 单页；摄氏输入；华氏输出；输入校验；换算；重置；自动化测试；本地运行说明 |
| 本期不包含 | 华氏转摄氏；其他温标；后端；数据库；网络请求；远程部署；账号；云端同步 |
| 固定规则 | `F = C × 9 / 5 + 32`；输入范围 -273.15 至 1000；结果最多两位小数并去除多余尾随零 |
| 可调整项 | 不影响验收的视觉样式、组件布局、测试框架和具体 Node.js/React 版本 |

## 3. 产品概念设计

### 3.1 产品逻辑

打开页面 → 输入摄氏温度 → 点击“换算” → 去除前后空格 → 校验普通十进制格式 → 校验数值范围 → 按公式计算 → 四舍五入并显示华氏结果。

校验失败时立即停止，不显示本次或上一次的有效结果。用户从任何页面状态点击“重置”，均返回初始状态。

| 换算页面 | 输入校验 | 处理空值、格式、特殊数值和范围 | P0 |
| 换算页面 | 温度换算 | 执行固定公式 | P0 |
| 换算页面 | 结果展示 | 最多展示两位小数并去除无意义尾零 | P0 |

## 4. 全局规则

### 4.1 换算和显示规则

1. 计算公式固定为 `F = C × 9 / 5 + 32`。
2. 计算值按常规十进制四舍五入，最多保留两位小数。
3. 展示时移除多余尾随零，例如 `32`、`212`、`-459.67`。
4. 实现不得因二进制浮点误差导致规定验收样例不匹配。

### 4.2 输入规则

- 接受 -273.15 至 1000，包含两个边界。
- 去除前后空格后再解析；例如 ` 0 ` 等价于 `0`。
- 接受普通十进制整数或小数，可带 `+` 或 `-` 号。
- 拒绝空值、纯空白、科学计数法、`Infinity`、`NaN`、多个小数点、逗号小数分隔符和文字混合内容。
- 格式非法或越界时不显示有效换算结果；若此前已有结果，必须清除或隐藏。

### 4.3 生命周期约束

项目按已确认的纯线性瀑布路线推进。每次阶段转换必须形成唯一、追加式记录，至少包含阶段、输入、输出、责任人、授权人、评审结论、时间、阻塞项、下一阶段授权和需求追溯链接。记录不完整、评审未通过或追溯断裂时不得进入下一阶段。

### 5.2 核心功能明细

#### 5.2.1 换算（FR-001、FR-002、FR-004）

| 输入 | 计算 | 预期显示 |
| --- | --- | --- |
| `-273.15` | -273.15 × 9 / 5 + 32 | `-459.67 °F` |
| `-40` | -40 × 9 / 5 + 32 | `-40 °F` |
| `0` | 0 × 9 / 5 + 32 | `32 °F` |
| `100` | 100 × 9 / 5 + 32 | `212 °F` |
| `1000` | 1000 × 9 / 5 + 32 | `1832 °F` |

#### 5.2.2 校验（FR-003）

| 输入类别 | 示例 | 预期结果 |
| --- | --- | --- |
| 空值或纯空白 | `""`、`"   "` | 显示空值错误，不显示结果 |
| 前后空格 | `" 0 "` | trim 后按 0 换算 |
| 非数字 | `abc`、`10C` | 显示格式错误，不显示结果 |
| 特殊格式 | `1e2`、`Infinity`、`NaN`、`1,5` | 显示格式错误，不显示结果 |
| 低于下界 | `-273.16` | 显示范围错误，不显示结果 |
| 高于上界 | `1000.01` | 显示范围错误，不显示结果 |

#### 5.2.3 重置（FR-005）

点击“重置”必须同步清空摄氏输入、华氏结果和错误提示，并恢复可接受新输入的初始状态。
