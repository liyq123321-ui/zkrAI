# 交付一个仅在本机运行的长度单位换算器。用户输入英寸长度，点击“换算”后显示对应的厘米数；点击“重置”可清空输入和结果。 产品需求文档

## 背景与目标
- 交付一个仅在本机运行的长度单位换算器，减少英寸到厘米手工换算的错误。
- 提供打开即可使用的 React 单页界面。

## 用户场景
| 用户场景 | 描述 |
|---------|------|
| 正常输入 | 用户在 Microsoft Edge 中打开本地页面，输入 0 到 1000（含边界）的英寸值并点击“换算”，查看厘米结果 |
| 异常输入 | 用户输入空值、非法格式或超出范围的值时，查看对应错误提示 |
| 重置操作 | 用户点击“重置”后清空输入、结果和错误提示 |

## 功能需求
| 编号 | 优先级 | 需求描述 |
|------|--------|----------|
| FR-001 | MUST | 系统必须使用 React 实现可运行的单页长度换算界面，并提供“换算”和“重置”两个按钮 |
| FR-002 | MUST | 用户点击“换算”后，系统必须将合法英寸输入按 1 inch = 2.53 cm 计算为厘米；结果必须始终显示两位小数，并采用十进制 half-up 四舍五入 |
| FR-003 | MUST | 系统必须校验英寸输入。完全空值显示“输入不能为空”；纯空白、带“+”或“-”符号、前后空白、科学计数法、Infinity、NaN、包含文字、小数点后超过两位以及单独的“.”均显示“有非法输入”且不产生厘米结果。整数、最多两位小数、小数点结尾的数字（如“5.”）、省略整数部分的小数（如“.5”）和带前导零的小数（如“00.5”）均为合法格式。无符号数字超出 0 至 1000 范围时显示“请输入范围在 0-1000 以内”且不产生厘米结果 |
| FR-004 | MUST | 用户点击“重置”后，系统必须清空英寸输入、厘米结果及错误提示 |
| FR-005 | MUST | 项目必须提供覆盖合法输入 0、10、1000、0.79、0.8、0.01、5.、.5 和 00.5，以及完全空值、纯空白、单独的“.”、带“+”或“-”符号、其他非法格式和超出范围输入的测试，并覆盖十进制 half-up 四舍五入规则 |
| FR-006 | MUST | 项目必须提供简短的本地运行说明，明确使用 npm start 启动项目，并说明如何在 Microsoft Edge 中打开页面 |

## 非功能需求
| 编号 | 优先级 | 需求描述 |
|------|--------|----------|
| NFR-001 | MUST | 系统必须仅在本机运行，不得使用后端、数据库或网络请求 |
| NFR-002 | MUST | 交付页面必须可在 Microsoft Edge 中运行和验收 |

## 验收标准
| 编号 | 验收项 | 预期结果 | 验证方法 |
|------|--------|----------|----------|
| AC-001 | 启动项目后页面加载 | 页面成功加载，两个按钮均可操作 | 执行 npm start，在 Microsoft Edge 打开本地页面并检查界面与交互 |
| AC-002 | 输入 10、0、1000、0.79、0.8 和 0.01 并点击“换算” | 10 显示 25.30 cm，0 显示 0.00 cm，1000 显示 2530.00 cm，0.79 显示 2.00 cm，0.8 显示 2.02 cm，0.01 显示 0.03 cm；结果始终保留两位小数，并按十进制 half-up 规则舍入 | 在 Microsoft Edge 手工执行用例，并运行对应自动化或单元测试 |
| AC-003 | 输入各类非法格式 | 完全空值显示“输入不能为空”；纯空白、“.”及其他非法格式显示“有非法输入”；无符号越界数字显示“请输入范围在 0-1000 以内”；5.、.5 和 00.5 正常换算 | 在 Microsoft Edge 手工输入各类值并点击“换算”，同时运行输入校验测试 |
| AC-004 | 点击“重置”按钮 | 输入框、结果和错误提示全部清空 | 在 Microsoft Edge 分别对合法换算状态和错误状态执行重置操作 |
| AC-005 | 测试套件覆盖 | 测试覆盖 0、10、1000、0.79、0.8、0.01、5.、.5、00.5、空值、纯空白、“.”、符号输入、其他非法格式和越界输入，并验证对应结果或错误文案 | 检查测试文件，并执行交付物中声明的测试入口 |
| AC-006 | 本地运行说明 | 使用说明可完成本地启动和页面访问 | 检查项目文档并按说明执行 |
| AC-007 | 本机运行环境 | 核心功能可用，且运行过程中不依赖后端、数据库或网络请求 | 停止或不提供后端服务，断开网络后执行 npm start 并操作页面，检查源码及网络请求 |
| AC-008 | Microsoft Edge 兼容性 | 页面无阻断性兼容问题，所有功能和测试场景均可验收 | 使用 Microsoft Edge 按照运行说明启动并执行完整验收用例 |
